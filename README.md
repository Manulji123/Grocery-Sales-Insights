# Power BI Dashboard: QuickCart

## Overview
This repository contains a Power BI dashboard that visualizes insights from an online grocery store, including **sales performance, customer behavior, and product trends**.  
The dashboard is built using **Power BI**, with data sourced from **Excel** files and SQL queries.

## Features
- Interactive visuals (charts, tables, slicers)
- Key metrics and insights at a glance
- Drill-down and filtering capabilities
- Designed for **business analysis** and decision-making
